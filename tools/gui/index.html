Wipe standards

Each drive is erased with the strongest method it supports and the result is verified:

• NVMe — firmware cryptographic / block erase (NIST Purge).
• SATA SSD — ATA secure erase or TRIM discard.
• HDD — single-pass overwrite + zero (NIST Clear), verified.
The boot USB is never listed and can never be wiped.
